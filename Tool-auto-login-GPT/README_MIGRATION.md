# Legacy compatibility bridge

The canonical project is now the repository root: `Nexus_Studio_Engine`.

This directory contains one-release lifecycle bridges only. Use the root entrypoints:

- `..\run_nexus.bat`
- `..\run_nexus_stop.bat`
- `..\run_nexus_restart.bat`

Do not place source code, runtime data, browser profiles, virtual environments, or frontend dependencies here. This compatibility directory will be removed in the next release.
